## Commands

```bash
pnpm test          # all unit projects, once
pnpm test:watch    # watch mode
pnpm e2e           # Playwright (starts the dev server itself)
pnpm lint
pnpm format:check  # or pnpm format to fix
pnpm typecheck
pnpm build
pnpm bundle        # print the gzipped sizes; bundle:check enforces the budget
pnpm check         # lint + format check + typecheck + test + build + bundle check + SEO contract: CI's verify job
```

First-time Playwright setup on a machine:

```bash
pnpm --filter @bigsmall/web exec playwright install chromium
```

## Golden tests

`packages/core/test/golden/<category>.ts` holds rows of `{ value, from, to, expected, source, tolerance? }`, collected in `golden/index.ts`. Rows are TypeScript so a derived value is written as its defining ratio (`1 / 0.3048`) rather than a hand-rounded decimal. Every row cites where `expected` comes from: a standards document, or "Derived:" plus the exact definition used. The default tolerance is a relative 1e-12; rows that quote a published seven-digit figure (NIST SP 811 Appendix B) use `PUBLISHED_7_DIGITS` (1e-6) so the strict default stays strict everywhere else.

Adding a unit means adding at least one row that exercises it; a test fails when any registered unit has no row. The round-trip test covers every unit automatically at four magnitudes, judged on `max(|expected|, 1)` so tiny temperatures are not failed on floating-point cancellation.

## Registry integrity

`packages/core/test/registry.test.ts` fails on: duplicate or malformed ids, a unit in an unknown category, a category whose base unit is missing or not linear with factor 1, a missing source, fewer than three standard units in a category, a note over 140 characters, a non-positive factor, a change to the category order, and search-key collisions (name, plural, symbol, alias) within a category. Collisions across categories are allowed; they are the ambiguity the UI shows with category labels (`oz` today; docs/UX-SPEC.md §3).

## Parser

`packages/core/test/cooking.test.ts` holds Cooking (ADR 0021): every ingredient's id, keys, and FoodData Central citation; a cup of each weighing what USDA weighs it; conversions across volume and weight both ways, and exact within one; reading the ingredient a query ends with; ranking ingredient matches; the units Cooking lists.

`packages/core/test/parse.test.ts` holds the number grammar and the arithmetic. `/` and `-` belong to arithmetic and to unit symbols alike, so each new operator gets a test beside a unit that uses the same character (`5 km/h` is 5 and `km/h`; `5 -ft` is 5 and `-ft`).

## Settings and rounding

`apps/web/test/converter-settings.test.ts` checks Settings (ADR 0018): the sections and their names, the two layers (switches, Other's among them, and single units, presets, Custom, Show custom hidden units), the sections' order, remembered settings read back part by part (Display by what was changed, older versions migrated), a fresh visit's display, and the table and the matches arranged by a rule (shown sections in the cursor's order, the hidden apart, the box's unit always shown). `packages/core/test/rounded.test.ts` checks the rounded formats: places, fractions in the sizes chosen, each in the smallest size chosen, rounding below zero, float noise, and the values left to their digits.

## Theme contract

`test/themes.test.ts` parses each theme CSS file and checks the token contract and the contrast pairs from `src/lib/themes.ts`. A failing pair prints both colors and the achieved ratio.

## CI

`.github/workflows/ci.yml` runs on every push to `main` and every pull request:

- **verify**: install, lint, format check, typecheck, unit tests, build, bundle budget, SEO contract. `pnpm check` runs the same steps locally.
- **e2e**: install Chromium, run Playwright. The HTML report is uploaded on failure.

Both must pass. There is no manual override; fix the code or fix the test.

Both jobs run on a named image (`ubuntu-26.04`) with every action on its newest major. The comment above the jobs lists the pins and why; review them with the rest at each milestone (ADR 0005).
