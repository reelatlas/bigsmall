# Sources for the manual brand-chart capture (2026-10-20)

One folder per brand. Everything the compiled `../brand-charts.json` was read from:

- `screenshot-NN.png` — Sean's screenshots of the brand's size-guide pages, in the order they were shared.
- `pasted-text.txt` — the page text Sean copied out of the browser (tab-separated), verbatim, with a heading per table saying which page/toggle it came from. Where a table was transcribed from an image instead of pasted (UGG kids PDF guide), the file says so.
- `new-balance/` also has the two text files and two saved PDFs Sean attached (`Size_Guide_-_New_Balance.pdf`, `Size_Guide_width_-_New_Balance.pdf`); the PDFs are the same pages as the text files.

Checker note: the JSON was built from the pasted text where it exists (parsed, not retyped); screenshots were used to confirm layout and to settle the HOKA all-gender misalignment and the New Balance women's width row that split across lines.
