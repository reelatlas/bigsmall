The brand’s chart as the second value

What the converter’s Shoe size table could show once a brand is chosen (docs/research/shoe-sizes-2.md §5, decisions 1 to 7). ISO 19407’s value stays first in every row, as today; the brand’s own cell sits beside it in a second column headed with the brand and its line; a dash means the brand prints nothing for that row, so ISO’s value stands alone. The brand’s values are the brand’s cells as published on its own site, never computed; every input below is read from the record that wave 2 checked. The children’s rows show the beyond values the product shows today for an adult size.
