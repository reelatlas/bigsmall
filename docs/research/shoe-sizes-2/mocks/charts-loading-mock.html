The brands’ charts, loading and failed

Since ADR 0029 the brands’ 33 charts are a 7 KB file the page fetches once it is wanted, cached by a hash in its name. These are the only moments a visitor could see it being fetched; the numbers below are illustrative.

  • When it fetches: Shoe size is opened, a brand is in the box (a link with brand=nike), or a brand’s name is begun in the box (nik), so by Enter it is usually here.
  • How long: one small request, typically tens of milliseconds on broadband, a second or two on a weak phone connection; then never again in that browser until the file changes.
  • What you see meanwhile: state 1 or 2 below. If the request fails, state 3, and the next time Shoe size is wanted it tries again.
